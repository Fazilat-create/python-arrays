Слайд 2 · Поиск

Поиск элемента 🔍

Как найти нужное значение в массиве? Перебираем элементы и сравниваем с искомым.

nums = [4, 8, 15, 16, 23, 42] target = 16   for i in range(len(nums)): if nums[i] == target: print("Найдено на позиции", i) break
💡
break — прерывает цикл, когда нашли нужное. Без него цикл продолжал бы работать.

Слайд 3 · Фильтрация

Фильтрация: отбираем лучшее ✨

Фильтрация — оставляем только те элементы, которые подходят под условие.

nums = [3, -1, 7, -5, 10, -2, 8]   # Оставляем только положительные числа positive = [] for x in nums: if x > 0: positive.append(x)   print(positive) # [3, 7, 10, 8]

Слайд 4 · Сортировка

Сортировка массива 📊

Отсортировать массив — расставить элементы по возрастанию или убыванию.

nums = [5, 2, 9, 1, 7]   # По возрастанию nums.sort() print(nums) # [1, 2, 5, 7, 9]   # По убыванию nums.sort(reverse=True) print(nums) # [9, 7, 5, 2, 1]

Слайд 5 · Сдвиг

Сдвиг элементов 🎠

Сдвиг влево — каждый элемент переходит на одну позицию влево, а первый оказывается в конце.

[1, 2, 3, 4, 5]
было
→
[2, 3, 4, 5, 1]
стало
arr = [1, 2, 3, 4, 5]   # 1. Запоминаем первый элемент first = arr[0]   # 2. Сдвигаем каждый элемент влево for i in range(len(arr) - 1): arr[i] = arr[i + 1]   # 3. Возвращаем сохранённый элемент в конец arr[-1] = first   print(arr) # [2, 3, 4, 5, 1]
