# 🌸 Одномерные массивы в Python — интерактивный учебник

Интерактивный учебник для 9 класса по теме «Одномерные массивы в Python».
Два урока с заданиями, автопроверкой и геймификацией.

## 📚 Что внутри

| Файл | Для кого | Содержимое |
|------|----------|-----------|
| `index.html` | все | главная страница с выбором урока и приветствием |
| `urok1.html` | ученики | Урок 1: основы работы с массивами |
| `urok2.html` | ученики | Урок 2: поиск, фильтрация, сортировка, сдвиг |
| `teacher.html` | учитель | панель управления с таймером |

## 🎯 Возможности

- 18 интерактивных слайдов с плавной навигацией
- 12 заданий с автоматической проверкой
- За каждое задание — цветочек 🌸
- В финале — букет с именем и персональным поздравлением
- Прогресс и имя сохраняются в браузере (localStorage)
- Визуализаторы: индексы, поиск, фильтрация, сортировка, сдвиг
- Работает офлайн, без установки и сервера
- Версия для учителя с таймером и переключением уроков

## 🚀 Как запустить локально

1. Скачайте все файлы в одну папку
2. Откройте `index.html` в браузере (двойным кликом)
3. Готово — всё работает

## 🌐 Как выложить на GitHub Pages

1. Создайте репозиторий на GitHub с именем `python-arrays`
2. Загрузите все файлы (через `git push` или кнопкой «Add file»)
3. Откройте Settings → Pages
4. В разделе Build and deployment выберите:
   - Source: `Deploy from a branch`
   - Branch: `main` / `/ (root)`
5. Нажмите Save и подождите 1–2 минуты
6. Сайт будет доступен по адресу:
   `https://ваш-логин.github.io/python-arrays/`

## 👩‍🏫 Для учителя

Откройте `teacher.html`. Там:

- Тот же урок, что и у учеников, но во встроенном окне
- Встроенный таймер на 45 минут с паузой и сбросом
- Быстрое переключение между уроками 1 и 2
- Кнопка «Открыть версию ученика» для показа в отдельной вкладке

**Горячие клавиши:**
- `Ctrl + 1` — урок 1
- `Ctrl + 2` — урок 2
- `Пробел` — старт/пауза таймера

## 🎓 Как работать ученикам

1. Открыть `index.html`
2. Выбрать «Урок 1»
3. Ввести имя — оно сохранится в браузере
4. Пройти слайды, выполнять задания → собирать цветочки 🌸
5. Перейти на «Урок 2» — прогресс сохранится
6. В финале — букет с именем
