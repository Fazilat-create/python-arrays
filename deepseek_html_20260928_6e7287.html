Слайд 2 · Поиск

Поиск элемента 🔍

Как найти нужное значение в массиве? Есть два способа: свой цикл или встроенные средства Python.

Способ 1: перебор с проверкой

nums = [4, 8, 15, 16, 23, 42] target = 16   for i in range(len(nums)): if nums[i] == target: print("Найдено на позиции", i) break

Способ 2: коротко, по-питоновски

if target in nums: print(nums.index(target))

Фильтрация: отбираем лучшее ✨

Иногда нужно оставить только те элементы, которые подходят под условие. Например, только положительные числа.

nums = [3, -1, 7, -5, 10, -2, 8]   # Оставляем только положительные числа positive = [] for x in nums: if x > 0: positive.append(x)   print(positive) # [3, 7, 10, 8]

Слайд 4 · Сортировка

Сортировка массива 📊

Отсортировать массив — значит расставить элементы по возрастанию или убыванию. В Python есть готовая сортировка, но интересно узнать, как она работает внутри.

Встроенная сортировка

nums = [5, 2, 9, 1, 7]   # По возрастанию nums.sort() print(nums) # [1, 2, 5, 7, 9]   # По убыванию nums.sort(reverse=True) print(nums) # [9, 7, 5, 2, 1]

Как работает «пузырьковая» сортировка

Алгоритм сравнивает соседние элементы и меняет их местами, если они стоят в неправильном порядке.

Слайд 5 · Сдвиг

Сдвиг элементов массива 🎠

Сдвиг влево на одну позицию: первый элемент перемещается в конец, остальные сдвигаются влево.

arr = [1, 2, 3, 4, 5]   # Запоминаем первый элемент first = arr[0]   # Сдвигаем все элементы влево for i in range(len(arr) - 1): arr[i] = arr[i + 1]   # Записываем первый в конец arr[-1] = first   print(arr) # [2, 3, 4, 5, 1]
