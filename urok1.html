Слайд 2 · Теория

Что такое массив

Слайд 3 · Индексы

Индексы: номер каждой ячейки 🔢

У каждого элемента есть свой номер — индекс. В Python отсчёт начинается с нуля!

Обычные индексы — считаем с начала

grades = [5, 4, 3, 5, 2]   # Индексы: 0 1 2 3 4   print(grades[0]) # 5 — первая оценка print(grades[2]) # 3 — третья оценка print(grades[4]) # 2 — пятая (последняя) оценка

Отрицательные индексы — считаем с конца 🔄

В Python можно считать не только с начала, но и с конца. Для этого используют отрицательные числа:

grades = [5, 4, 3, 5, 2]   # Обычные: 0 1 2 3 4 # С конца: -5 -4 -3 -2 -1   print(grades[-1]) # 2 — последний элемент print(grades[-2]) # 5 — предпоследний
💡
Правило: -1 — последний элемент, -2 — предпоследний, -3 — третий с конца. Так удобно, когда длина массива заранее неизвестна.

Слайд 4 · Изменение

Изменяем элементы массива 🔄

По индексу можно не только читать значение, но и записывать новое.

grades = [5, 4, 3, 5, 2]   # Было: индекс 4 → значение 2 # Меняем на 4 — теперь в массиве [5, 4, 3, 5, 4] grades[4] = 4   print(grades) # [5, 4, 3, 5, 4]
💡
Запись arr[i] = x означает: «положи в ячейку с номером i значение x». Старое значение стирается.

Слайд 5 · Перебор

Как пройтись по всем элементам? 🚶‍♀️

Для перебора используют цикл for. Есть два способа — оба важны.

Способ 1: по элементам (просто и коротко)

for grade in grades: print(grade)

На каждой итерации grade становится очередным значением массива. Если в массиве 5 элементов — цикл выполнится 5 раз.

Способ 2: по индексам (когда нужен номер)

for i in range(len(grades)): print(i, grades[i])
💡
Разбираем по частям:
• len(grades) — сколько элементов в массиве (например, 5)
• range(5) — числа 0, 1, 2, 3, 4 — то есть все допустимые индексы
• Значит, for i in range(len(grades)) — «пройди по всем индексам от 0 до последнего»

Слайд 6 · Практика

Сумма и среднее значение ➕

Одна из частых задач — найти сумму или среднее элементов массива.

Сумма — двумя способами

grades = [5, 4, 3, 5, 2, 4, 5]   # Способ 1: вручную через for total = 0 for g in grades: total = total + g print("Сумма:", total)   # Способ 2: встроенная функция sum() print("Быстро:", sum(grades))

Среднее арифметическое

# Среднее = сумма / количество avg = sum(grades) / len(grades) print("Среднее:", avg)

Считаем количество одинаковых элементов

Метод .count(x) возвращает, сколько раз значение x встречается в массиве.

# Сколько пятёрок в массиве? fives = grades.count(5) print("Пятёрок:", fives) # Пятёрок: 3
