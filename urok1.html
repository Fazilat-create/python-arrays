Слайд 3 · Индексы

Индексы — номер каждой ячейки 🔢

У каждого элемента есть свой номер — индекс. В Python отсчёт начинается с нуля!

grades = [5, 4, 3, 5, 2]   # Индексы: 0 1 2 3 4   print(grades[0]) # 5 — первая оценка print(grades[2]) # 3 — третья оценка

Слайд 4 · Считаем с конца

Отрицательные индексы 🔄

Если считать с начала неудобно — можно считать с конца. Для этого используют отрицательные числа!

fruits = ["яблоко", "банан", "вишня", "груша", "слива"]   # Обычные: 0 1 2 3 4 # С конца: -5 -4 -3 -2 -1   print(fruits[-1]) # слива — последний print(fruits[-2]) # груша — предпоследний
💡
Правило: -1 — последний, -2 — предпоследний, -3 — третий с конца.

Слайд 8 · Перебор по индексам

Перебор с номерами 🔢

Иногда нужен не только элемент, но и его номер. Тогда перебирают по индексам через range(len(...)).

nums = [5, 3, 8]   for i in range(len(nums)): print(i, nums[i])   # 0 5 # 1 3 # 2 8
💡
Как это читается:
• len(nums) — сколько элементов (3)
• range(3) — числа 0, 1, 2
• i — индекс, nums[i] — элемент
